# OmniInstall Install Plan Specification

## Purpose

Defines the data structure produced by the Source Resolver and consumed by the Install Engine.

---

## Example

```yaml
application_id: obs-studio
source_type: apt
source_identifier: obs-studio
risk_level: low
requires_privilege: true
verification:
  - command: obs
```

---

## Required Fields

- application_id
- source_type
- source_identifier
- risk_level
- verification

---

## Optional Fields

- requires_confirmation
- explanation
- repository_changes
- expected_version

---

## Validation

Install plans must be explicit.

The Install Engine must reject ambiguous plans.

---

## Summary

Install plans are immutable execution instructions generated by the Source Resolver.
