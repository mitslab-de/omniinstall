# Contributing to omniinstall

Thank you for your interest in contributing! Contributions are what make the community succeed.

## Ground rules
- Follow the Code of Conduct.
- Keep discussions respectful and constructive.
- Before starting a large change, open an issue to discuss your approach.

## Getting started
1. Create a topic branch off `main`.
2. Implement the change and add tests where it makes sense.
3. Run the project checks / linting and ensure everything passes.
4. Open a Pull Request targeting `main`.

## Development workflow
- Keep PRs focused and small.
- Write meaningful commit messages.
- Describe the problem, solution, and any trade-offs in the PR description.
- Expect squash-merging; we optimize for a clean history.

## Documentation
If your change adds new behavior, update the documentation or add a short section to the wiki.

## Security
Please **do not** disclose security vulnerabilities in public issues or PRs.
Report security issues privately to **mail@mitslab.de**.

Happy hacking!
