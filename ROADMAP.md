# Roadmap

This roadmap is a living document. Priorities can change as the community grows.

## Now (0-3 months)
- Solidify core design and architecture
- Implement recipe schema, validation, and safety mechanisms
- Build CLI installer with support for multiple package managers
- Add initial developer documentation and examples

## Next (3-6 months)
- Cross-distro recipe repository (community-driven)
- Build a recipe discovery UX (search, tags, ratings)
- CI pipelines for recipe validation/testing
- Basic UI for monitoring installs

## Later (6-12 months)
- Rich dependency resolution across ecosystems
- Recipes for full environments (gaming, dev, media, etc.)
- Contribution programs and maintainers team structure
- Telemetry opt-in to improve recipe quality (privacy-first)

If you want to work on any of these, open a Discussion or Issue to coordinate.
