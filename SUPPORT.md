# Support

If you need help with omniinstall, please follow these steps:

1. Read the `README.md` and the documentation in the `docs/` folder.
2. Search existing issues and discussions to see if your question has already been answered.
3. For **bugs**, open a new GitHub Issue using the bug report template.
4. For **feature ideas**, open a GitHub Issue using the feature request template.
5. For **recipe requests** or assistance with writing recipes, open a Discussion in the “Recipes” category (preferred) or open an issue.
6. For anything else, you can email **mail@mitslab.de**.

## Response time

This project is maintained on a best-effort basis. Response times may vary depending on availability.
